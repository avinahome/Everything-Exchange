# Everything Exchange - User Manual

## 📱 Getting Started

### Installation
1. Download the Everything Exchange APK file
2. Enable "Install from Unknown Sources" in your Android settings
3. Tap the APK file to install
4. Launch the app from your app drawer

### First Time Setup
1. **Create Account**: Tap "Register" and enter a username and password
2. **Login**: Use your credentials to access the app
3. **Permissions**: Grant camera and storage permissions when prompted

## 🏠 Managing Your Inventory

### Adding Items
1. Navigate to the **Inventory** tab
2. Tap the **+** button in the top-right corner
3. Fill in item details:
   - **Name**: What is the item?
   - **Description**: Additional details about the item
   - **Category**: Type of item (Electronics, Furniture, etc.)
   - **Purchase Price**: What you paid (optional)
   - **Current Value**: What it's worth now (optional)
   - **Condition**: Select from New, Like New, Good, Fair, Poor
4. **Take Photo**: Tap "Take Photo" to capture an image
5. Tap **Save** to add the item

### Managing Items
- **View**: Browse your inventory in the main list
- **Edit**: Tap the menu (⋮) on any item and select "Edit"
- **Delete**: Tap the menu (⋮) on any item and select "Delete"
- **Search**: Use the search bar to find specific items

### Export Your Data
1. In the **Inventory** tab, tap the download icon
2. Choose your export format:
   - **CSV**: Spreadsheet format for data analysis
   - **PDF**: Formatted report for printing or sharing
3. The file will be saved and you can share it with other apps

## 🏪 Creating Listings

### Selling Items
1. Navigate to the **Listings** tab
2. Tap the **+** button to create a new listing
3. Select an item from your inventory
4. Set your asking price
5. Add a compelling title and description
6. Your listing is now live and discoverable by other users

### Managing Listings
- **View**: See all your active and inactive listings
- **Edit**: Update pricing or description
- **Deactivate**: Remove from public discovery
- **Track Offers**: Monitor incoming offers on your items

## 🔍 Discovering Items

### Finding Items to Buy
1. Navigate to the **Discover** tab
2. Browse available items from other users
3. Use the search bar to find specific types of items
4. Tap on any item to view full details

### Making Offers
1. Find an item you're interested in
2. Tap **Make Offer**
3. Enter your offer amount
4. Add an optional message to the seller
5. Submit your offer and wait for a response

### Managing Your Offers
- **Track Status**: See if offers are pending, accepted, or rejected
- **Withdraw**: Cancel offers you no longer want to make
- **Negotiate**: Respond to counter-offers from sellers

## 🔧 Troubleshooting

### Common Issues

**App Won't Install**
- Enable "Unknown Sources" in Android settings
- Ensure you have sufficient storage space
- Try redownloading the APK file

**Camera Not Working**
- Grant camera permission in app settings
- Check that your device camera is functioning
- Restart the app and try again

**Items Not Saving**
- Ensure all required fields are filled
- Check available storage space
- Restart the app if issues persist

**Export Not Working**
- Grant storage permission when prompted
- Ensure you have space for the export file
- Try a different export format

### Performance Tips
- **Regular Cleanup**: Delete items you no longer own
- **Photo Management**: Remove unnecessary photos to save space
- **App Updates**: Keep the app updated for best performance

### Getting Help
- **Check Settings**: Most issues can be resolved in Android settings
- **Restart App**: Close and reopen the app to refresh
- **Device Restart**: Reboot your device if problems persist
